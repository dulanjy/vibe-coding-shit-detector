# Examples

The bundled example describes a fictional catalog API. It is intentionally small enough to inspect while showing how scores, gates, limitations, findings, and the highest-leverage improvement fit together.

- [audit-report.sample.md](audit-report.sample.md) — abbreviated human-readable report
- [audit-result.sample.json](audit-result.sample.json) — matching machine-readable result

The example is not a benchmark or an endorsement of a score. Real audits must cite the audited repository's actual paths, lines, commands, and evidence gaps.
