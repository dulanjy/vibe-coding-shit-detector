# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and versions follow [Semantic Versioning](https://semver.org/).

## [0.2.0] - 2026-09-17

### Added

- `npx skills` quick-install guidance and explicit Agent Skills compatibility.
- Chinese README, fictional end-to-end audit examples, and behavioral evaluation prompts.
- Contribution and security-reporting guidance plus an audit-quality issue template.
- JSON Schema validation of the sample result in the test suite.
- Linux and Windows CI across Python 3.10 and 3.12.

### Changed

- Reworked the repository landing page around quick evaluation, safety boundaries, visible outputs, and verifiable limitations.
- Documented the package layout and current calibration status.

## [0.1.0] - 2026-09-17

### Added

- Initial `software-engineering-health-audit` Skill.
- Ten-dimension Engineering Health model and seven-signal Vibe Slop model.
- Evidence Confidence, Critical Gates, Repository Amnesia Test, and Controlled Change Test.
- Markdown report template, JSON Schema, read-only inventory and Git coupling helpers.
- Initial tests and GitHub Actions validation.
