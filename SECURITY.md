# Security policy

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for issues that could expose credentials, execute repository code unexpectedly, write outside an explicitly selected output location, or bypass the Skill's read-only boundary.

Do not include live secrets, private repository content, customer audit reports, or exploit details in a public issue.

For ordinary false positives, scoring disagreements, or missing evidence handling, use the public audit-quality issue template instead.

## Supported version

Security fixes are applied to the latest release. This project is an Agent Skill and local analysis toolkit, not a hosted service.
